Explainer Report and sources Data
The data

Every file behind the numbers

The files are as downloaded on 12 November 2026. manifest.csv gives the address, size and SHA-256 of each one. fetch.py downloads them again and analyze.py computes the numbers in analysis.json.

Produced by fetch.py (standard library only). Run python -X utf8 fetch.py to redo all downloads, or python -X utf8 fetch.py noaa nasa for the sources whose name contains a word. manifest.csv has one row per source: file, URL, date read, size, SHA-256 and status. Large downloads go to cache/ (not committed). All files outside cache/ are committed as downloaded, with no edits (the OWID files are extracts).

The cloud container reaches only GitHub and the Berkeley Earth bucket. The agency sites (NOAA, NASA, Met Office, ECMWF, NSIDC, JMA) return 403 there. Run the script on a home machine for those; a failed source stays in the manifest as failed. The agency files in primary/ were downloaded from a home machine on 2026-11-12 with curl, from the URLs in fetch.py and with its User-Agent. Each was checked for HTTP 200 and for data, not an HTML error page.

Notes:

  • The IGCC annual temperature is a mean of several datasets, so it is a little lower than Copernicus ERA5 or Berkeley Earth alone.
  • In igcc/earth_energy_imbalance/earth_energy_imbalance.csv the total column stops at 2020. The ocean columns continue to 2024. The last row has no year.
  • Our World in Data co2 is fossil fuel and cement CO2 before the subtraction of cement carbonation. The Global Carbon Budget headline is lower for that reason.
  • The download through archive/<sha>.tar.gz is blocked in the cloud container, so fetch.py uses git clone for the IGCC repository.
  • Each agency dataset uses its own baseline (see the table). Rebase before you compare anomalies.
  • The NOAA GML and NOAA STAR files start with # comment lines (citation, method, notes). The NOAA NCEI file has three # lines (title, units, base period). Skip them when you parse.
  • GISTEMP has a title line (Land-Ocean: Global Means) before the header row.
  • The two JMA files are Shift-JIS (cp932), not UTF-8. Read them with encoding="cp932". Headers: 年,偏差 (year, anomaly) and 年,世界全体,北半球,南半球 (year, world, NH, SH). Values carry an explicit + sign.
  • HadCRUT.5.0.2.0 is superseded; its monthly file stops at 2025-02. fetch.py reads HadCRUT.5.1.0.0 since 2026-11-12.
  • The 2026 row of HadCRUT5 annual and the ERA5 days after the last FINAL date are not final values.
  • NSIDC changed the source dataset from NSIDC-0051 to NSIDC-0803 in recent years (column source_dataset).
